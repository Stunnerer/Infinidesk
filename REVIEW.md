# Результаты ревью

Проверены исходники и заголовки, Meson, Nix, CI, desktop entry и конфигурация
инструментов разработки. Ниже перечислены исправленные дефекты. Это не
гарантия отсутствия других ошибок: поведение на физическом GPU и устройствах
ввода требует отдельной интерактивной проверки.

## Исправления

| Область | Дефект и исправление |
| --- | --- |
| Alt+Tab | Уничтоженное выбранное окно оставляло висячий указатель. Выбор обновляется при unmap/destroy; скрытые окна пропускаются; отсутствие output обрабатывается безопасно. |
| Alt+Tab | Фокус ошибочно считался равным первому элементу списка. Начальный выбор теперь учитывает реальный фокус; добавлены обратный обход, отмена и ограничение списка высотой экрана. Изменения запрашивают кадр. |
| Конфигурация | Незакрытая строка `startup` зацикливала парсер. Разбор проверяет строки, разделители и конец массива; частично разобранные команды освобождаются. |
| Конфигурация | `NaN`, бесконечность, нулевой/отрицательный масштаб и числовой мусор попадали в wlroots. Добавлена проверка масштаба, обработка комментариев секций и сохранение рабочих биндов при ошибке чтения. |
| Конфигурация | Устранены утечки при переходе к стандартным биндам, арифметика перед началом пустой строки и гонка перезаписи при создании файла. Стандартный терминальный бинд согласован со справкой; поддерживается `XDG_CONFIG_HOME`. |
| Клавиатура | Отпускание перехваченной клавиши попадало приложению без нажатия. Состояние перехваченных клавиш хранится на устройстве и исключается из keyboard enter. |
| Клавиатура | Сочетания с дополнительными модификаторами конфликтовали, VT-переключение не распознавало физические F1–F12, Super мог сбрасываться при отпускании второго модификатора. Исправлены сопоставление и обновление состояния; отключение клавиатуры обновляет seat. |
| Фокус | Команда закрытия выбирала верхнее окно вместо сфокусированного. Исправлены закрытие, восстановление фокуса после unmap, деактивация окон при фокусе панели и восстановление другого exclusive layer. |
| Мышь | Рисование и некоторые resize-клики попадали клиентам; отпускание посторонней кнопки завершало drag. События действий композитора потребляются парами, завершение привязано к исходной кнопке. |
| Рисование | Очистка во время штриха теряла выделенную память; изменения не запрашивали кадры. Исправлены освобождение, история и перерисовка. Длинные линии обрезаются до видимой области до растеризации. |
| Отрисовка | Не рисовались программные курсоры, а анимации могли остановиться после первого кадра. Добавлены курсор и планирование кадров, обработка ошибок submit/commit. |
| Отрисовка | Изменение поверхности могло не обновить экран, когда видимость в scene расходилась с масштабированным холстом. Commit/destroy поверхностей теперь явно запрашивают кадры. |
| Геометрия | На дополнительных мониторах окна рисовались без смещения output, тогда как курсор использовал координаты layout. Смещения согласованы для окон, popup, рисунков, размещения, snapping и hit testing. |
| Геометрия | Scene helper уже учитывал XDG geometry, но смещение вычиталось повторно. Устранён двойной сдвиг; input region клиента соблюдается. Анимация появления сохраняет геометрию ввода. |
| Оформление | Скругления закрашивали нижнее содержимое серым цветом. Вместо масок используется clipping; исправлены premultiplied alpha и трансформация буферов поверхностей. |
| Размер окон | При resize игнорировались максимальные размеры клиента. Ограничения учитываются перед отправкой configure. |
| Сбор окон | Gather вычислял центр viewport, но не использовал его и оставлял совпадающие окна наложенными. Теперь видимые окна собираются вокруг активного output с минимальным зазором. |
| Навигация | Ручной pan/zoom продолжал конкурировать с анимацией перехода. Ручное действие отменяет переход; нулевое событие остановки прокрутки больше не меняет zoom. |
| Layer shell | Background/bottom перехватывали ввод поверх приложений. Hit testing согласован с порядком рисования; popup больше не рисуются дважды. |
| Layer shell | Удаление output оставляло layer wrappers со ссылкой на освобождённый output. Поверхности закрываются до освобождения wrapper и деревьев. |
| Layer shell | Панели не пересчитывались при изменении размеров/масштаба output; unmap продолжал занимать exclusive zone. Исправлены перерасчёт, порядок зон и перенос между слоями. |
| Popup | Reposition и layer popup не получали ограничений. Общий обработчик ограничивает начальное положение и reposition, включая вложенные popup, без сохранения сырой ссылки на view. |
| Завершение | Освобождались не все ресурсы, а порядок teardown мог оставлять callbacks к уже уничтоженному seat. Backend, cursor, scene, allocator, renderer и Pango освобождаются явно в нужном порядке. |
| Процессы | SIGINT/SIGTERM обрабатывались до создания display; дочерние shell-процессы не собирались. Сигналы перенесены в event loop, дети собираются автоматически и получают нормальную маску сигналов перед exec. |
| Сборка | Зависимость допускала несовместимые версии wlroots. Ограничена веткой 0.18; тесты подключены к Meson и CI/Nix. Удалён локальный абсолютный Nix-путь из `.clangd`. |
| Пакет | В `.deb` отсутствовали Wayland client library и desktop entry. Добавлены файлы и поиск зависимостей bundled wlroots через `$ORIGIN`. Nix outputs ограничены поддерживаемыми Linux-платформами. |

## Проверено автоматически

- `meson compile -C build`: успешно, без предупреждений компилятора.
- `meson test -C build --print-errorlogs`: оба набора проходят.
- Тестовый настоящий Wayland-клиент создаёт окно, панель и popup, выполняет
  reposition; сервер отключает монитор с живой панелью; окно уничтожается при
  активном Alt+Tab.
- Проверены US-позиции биндов при активной русской раскладке, перехват отпускания,
  дополнительные модификаторы и отключение клавиатуры.
- Отдельный headless-запуск с двумя output и временным конфигом завершился по
  SIGTERM с кодом 0.
- Valgrind на core/protocol сценарии: 0 ошибок, 0 байт definite/indirect leaks.
  В последнем прогоне остаётся `possibly lost: 394 bytes`: 26 байт внутри
  `pango_language_from_string` и 368 байт TLS потока Pango/GLib, а также
  доступные глобальные кэши библиотек.
- `git diff --check`: успешно.

Тесты используют временные данные и не запускают пользовательский `startup`.
Для протокольного теста нужны доступные Unix socket credentials; ограниченная
песочница этого окружения блокировала их, поэтому он выполнен вне неё.
Сборки Nix и `.deb` здесь не запускались.

## Проверить в запущенном композиторе

1. Два физических монитора с разным DPI: перенос окон, popup у краёв,
   клики по содержимому, отключение монитора с панелью.
2. Alt+Tab/Alt+Shift+Tab, Escape, закрытие выбранного окна, смена заголовка;
   фокус через мышь и launcher с exclusive/on-demand keyboard interactivity.
3. Super+drag, resize всех краёв, отпускание другой кнопки во время drag,
   закрытие перетаскиваемого окна; работа биндов с US/RU, Caps Lock и Num Lock.
4. Панорамирование, wheel/pinch, прерывание анимации перехода; GTK/Qt popup
   и вложенные меню при zoom 0.1, 1 и 4.
5. Рисование поверх окна/панели, очистка во время штриха, undo/redo, цвет,
   перенос указателя между мониторами и изменение разрешения.
6. Программный курсор, fractional scaling во вложенном Wayland backend,
   прозрачность и скругления поверх другого окна или обоев.
7. На реальной VT проверить Ctrl+Alt+F1–F12; собрать Nix и пакет в CI.
