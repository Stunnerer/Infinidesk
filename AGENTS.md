# Инструкции для агентов

## Общение

- Общайся с пользователем по-русски и переходи сразу к сути. Не начинай каждый ответ с «Да».
- Сообщай, что изменено, как проверено и что требует проверки в запущенном композиторе.

## Проект

- Infinidesk — Wayland-композитор на C11 и wlroots 0.18. Исходники находятся в `src/`, публичные заголовки — в `include/infinidesk/`.
- Сборка настроена в `meson.build`; `flake.nix` предоставляет зависимости и dev shell.
- Окна размещаются в координатах бесконечного холста. `src/canvas.c` преобразует их в экранные координаты; `src/view.c` рисует окна и popup; `src/server.c` выполняет hit testing. При изменении геометрии согласовывай все три пути.
- Виды окон и layer surfaces рисуются собственным render pass в `src/output.c`. Сцена wlroots также используется для управления поверхностями, но её координаты не заменяют координаты холста при отрисовке.
- `src/xdg_shell.c` обрабатывает XDG popup. Их ограничения задаются в координатах корневой поверхности, с учётом положения окна, viewport и масштаба холста.
- Бинды из `src/config.c` сопоставляются с физическими позициями US-клавиатуры в `src/keyboard.c`; события приложений должны продолжать использовать текущую раскладку.
- Пользовательский конфиг находится в `~/.config/infinidesk/infinidesk.toml`. При добавлении параметра обновляй значения по умолчанию, разбор файла и README; существующие конфиги должны продолжать работать.

## Проверка изменений

- Собери проект командой `meson compile -C build`. Если каталога сборки нет, сначала выполни `meson setup build` (или используй `nix develop`).
- Проверь `git diff --check`. В проекте пока нет автоматических тестов; для изменений ввода, popup и отрисовки описывай необходимую ручную проверку и не выдавай успешную сборку за проверку поведения в работающем композиторе.
- Логи wlroots идут в stderr, отдельный файл композитор не создаёт. Для воспроизведения падения запускай `./build/infinidesk --debug 2>&1 | tee /tmp/infinidesk.log`; при наличии дампа проверь `coredumpctl`.
- Не изменяй сгенерированные файлы в `build/` и `result/`. Сохраняй стиль C из `.clang-format` (LLVM, отступ 4 пробела).
